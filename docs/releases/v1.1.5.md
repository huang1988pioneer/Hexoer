# Hexoer v1.1.5

This patch release clarifies Codeberg authentication and Pages deployment requirements.

## Changes

- Adds Codeberg-specific HTTPS credential guidance for expired or incorrect credentials.
- Explains that Codeberg Pages normally publishes static output from the `pages` branch with a webhook, or via Forgejo Actions.
- Updates multi-platform Pages copy so Codeberg is not described like GitLab Pages CI.

## Notes

- Codeberg push still requires the local Git credential to use a valid Codeberg access token or SSH key.
- Windows artifacts are not code-signed, so Windows SmartScreen may show an unknown publisher warning.
