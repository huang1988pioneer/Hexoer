# Hexoer v1.1.1

This patch release aligns Hexoer with the Hugoer release flow and documents the latest GitHub Pages deployment improvements.

## Changed

- Added `scripts/publish.ps1` as the single release entry point for Windows publishing and packaging.
- Updated Windows package scripts to produce `1.1.1` artifacts and pass version metadata into `dotnet publish`.
- Kept the existing portable ZIP, Inno Setup installer, and fallback PowerShell installer flow.

## Deployment Improvements

- Improved GitHub Pages deployment for existing repositories.
- Added online deployment version monitoring so the app can tell whether Pages has published the latest pushed site.
- Clarified collaborator/admin permission handling for GitHub Pages setup.

## Notes

- Windows artifacts are not code-signed, so Windows SmartScreen may show an unknown publisher warning.
- End users still need Node.js, npm, and Git installed to operate Hexo projects.
