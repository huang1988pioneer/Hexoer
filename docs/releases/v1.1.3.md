# Hexoer v1.1.3

This patch release fixes GitLab and Bitbucket repositories that already contain a platform-generated README commit.

## Changes

- Automatically resolves README-only add/add merge conflicts during safe remote synchronization.
- Keeps the platform README as `README.md` and saves the local Hexo README as `README.hexo.md` or the next available backup name.
- Reuses the same safe merge helper for initial repository connection and push-retry synchronization.

## Notes

- Hexoer still aborts and stops before pushing when conflicts involve files other than `README.md`.
- Windows artifacts are not code-signed, so Windows SmartScreen may show an unknown publisher warning.
