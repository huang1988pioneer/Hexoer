# Hexoer v1.1.4

This patch release adds automatic GitLab Pages CI setup for Hexo projects.

## Changes

- Adds `.gitlab-ci.yml` automatically when deploying to a GitLab repository.
- The GitLab CI job installs npm dependencies, runs `npx hexo generate`, and publishes the generated `public/` directory with `pages: true`.
- Updates UI copy so GitLab is no longer described as a manual CI setup path.

## Notes

- GitLab Pages still requires the project CI/CD pipeline to run successfully before the site URL stops showing 404.
- Windows artifacts are not code-signed, so Windows SmartScreen may show an unknown publisher warning.
