# Hexoer v1.1.2

This patch release tightens the multi-platform Pages flow after testing against GitLab and Bitbucket repositories.

## Changes

- Added a second-chance `fetch` + safe merge + retry when Git push is rejected because the remote branch has newer commits.
- Improved GitLab and Bitbucket failure messages so users know when local Git credentials differ from the browser account.
- Allowed Hexoer to retarget `origin` when the user intentionally selects a different repository.
- Expanded Markdown preview support with Markdig advanced extensions.
- Added an npm latest-version check for Hexo and surfaces update guidance in the environment screen.
- Fixed long repository and Pages summaries wrapping in the multi-platform Pages view.

## Notes

- Hexoer still avoids force-push. If a merge conflict occurs, it aborts the merge and asks the user to resolve it manually.
- Windows artifacts are not code-signed, so Windows SmartScreen may show an unknown publisher warning.
