# Hexoer v1.1.6

Fixes Codeberg Pages branch handling and provider-specific deployer settings.

## Changes
- Uses `pages` as the default push branch for Codeberg `pages` repositories instead of trying to merge a missing `origin/main`.
- Treats missing fetched remote branches as empty remote content, so Hexoer stops before unsafe merges instead of merging a non-existent ref.
- Prevents GitHub deployer URLs and `gh-pages` defaults from leaking into Codeberg settings; Codeberg deployer defaults now use `pages`.
- Updates the deployer branch placeholder to match the selected provider.
